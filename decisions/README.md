# Decision Records

Durable architecture and workflow decisions live in `decisions/active/`. Superseded records move unchanged to `decisions/archive/` with a pointer to the replacement.

Each record contains: status/date, problem and constraints, decision, alternatives, consequences, migration notes, and a concrete review condition.
