# Visual Direction

Lindenhafen is a premium stylized-realistic German miniature: believable Altbau blocks, pitched roofs, civic landmarks, modern campus architecture, industrial massing, dense trees, traffic, pedestrians, restrained materials, and strong aerial silhouettes.

The camera moves from city overview to building focus without cuts. One local shadow-casting sun, atmospheric fog, emissive windows, and a slow cosmetic day/night cycle create depth without obscuring data. Overlays must remain readable in the world and are supplemented—not replaced—by the HUD.

The vertical slice uses procedural geometry so architectural and rendering systems can be proven before licensed GLB assets enter the pipeline.
